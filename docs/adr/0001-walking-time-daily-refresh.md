# 도보 시간은 TMAP 보행자 경로로 구하고 매일 전체를 다시 계산한다

네이버 Directions API는 자동차 경로만 주기 때문에, 실제 보행 경로 기준의 도보 시간은 TMAP 보행자 경로 API로 구한다. TMAP 약관은 "얻어진 데이터는 저장 후 24시간 이상 사용할 수 없다"고 정하므로, 가게를 추가할 때 한 번 계산하고 하루에 한 번 모든 가게의 도보 시간을 다시 계산해 덮어쓴다. 이렇게 하면 화면을 볼 때 API를 부르지 않으면서도 저장된 값이 24시간을 넘지 않는다. 호출 수는 가게당 하루 1건이라 무료 한도(하루 1,000건) 안에 든다.

## Considered Options

- 조회할 때 계산하고 24시간 캐시: 호출 수가 조회량에 따라 늘고 첫 조회가 느려서 기각.
- OpenRouteService(OpenStreetMap): 저장 제한은 없지만 한국 횡단보도와 골목 데이터가 부정확해서 기각.

## Consequences

- 매일 도는 예약 작업이 멈추면 도보 시간이 약관상 쓸 수 없는 값이 된다. 가게가 900곳을 넘으면 무료 한도를 넘는다.
