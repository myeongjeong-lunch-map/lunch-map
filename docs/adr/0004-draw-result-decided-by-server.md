# 추첨 결과는 서버가 정하고, 연출은 그 결과를 보여 주기만 한다

조장이 추첨을 시작하면 서버가 추첨통에 든 가게 가운데 하나를 가중치(넣은 횟수)에 비례하는 확률로 뽑아 저장한다. 그다음 팀원 모두에게 같은 결과를 보낸다. 경주나 플링코 같은 연출은 이미 정해진 결과로 끝나도록 화면에서 그려 낸다. 결과를 조장 브라우저에서 정하면 마음에 들 때까지 몰래 다시 돌릴 수 있다. 그러면 "의견이 나뉠 때 공정하게 하나로 정한다"는 추첨의 목적이 깨진다.

처음에는 추첨 한 번으로 끝나고 다시 돌릴 수 없게 했다. 그런데 써 보니 뽑힌 가게가 마음에 들지 않는 경우가 있었다. 그래서 조장이 같은 추첨통으로 다시 뽑을 수 있게 바꿨다. 대신 공정성은 투명성으로 지킨다. 회차마다 뽑힌 가게를 서버에 모두 저장하고 팀원 모두에게 보여 주며(1차 ○○ → 2차 △△), 다시 뽑을 때는 앞 회차에 뽑힌 가게를 모두 빼고 뽑는다. 조장이 "이걸로 결정"을 눌러야 추첨통이 닫히고, 결정한 가게만 추첨 기록에 남는다. 첫 추첨 뒤에는 추첨통에 가게를 더 넣거나 뺄 수 없다.

## Considered Options

- 조장 브라우저에서 뽑아 결과만 알림: 몰래 다시 돌리는 것을 막을 수 없어 기각.
- 연출(경주의 물리 계산 등)이 결과를 정함: 확률이 가중치와 정확히 맞는다고 보장하기 어려워 기각.
- 다시 뽑기 없이 한 번으로 끝: 처음 결정이었으나 마음에 안 드는 결과를 되돌릴 방법이 없어 바꿈.
- 추첨 뒤 닫고 "같은 가게로 새 추첨통 열기": 회차가 흩어져 몇 번 다시 뽑았는지가 잘 안 보여 기각.

## Consequences

- 회차마다 결과가 한 줄씩 쌓인다(draw_results). 추첨통은 결정하거나 취소할 때까지 열려 있다.
- 다시 뽑을 후보가 1곳뿐이면 다시 뽑기를 막는다.
- 연출은 결과를 입력으로 받아야 한다. 경주는 정해진 가게가 1등이 되도록, 플링코는 공이 정해진 칸에 떨어지도록 그린다.
- 나중에 들어온 팀원은 저장된 결과로 같은 연출을 다시 볼 수 있다.
