# 추첨 결과는 서버가 정하고, 연출은 그 결과를 보여 주기만 한다

조장이 추첨을 시작하면 서버가 추첨통에 든 가게 가운데 하나를 가중치(넣은 횟수)에 비례하는 확률로 뽑아 저장한다. 그다음 팀원 모두에게 같은 결과를 실시간으로 보낸다. 경주나 플링코 같은 연출은 이미 정해진 결과로 끝나도록 화면에서 그려 낸다. 결과를 조장 브라우저에서 정하면 마음에 들 때까지 다시 돌릴 수 있다. 그러면 "의견이 나뉠 때 공정하게 하나로 정한다"는 추첨의 목적이 깨진다.

## Considered Options

- 조장 브라우저에서 뽑아 결과만 알림: 다시 돌리기를 막을 수 없어 기각.
- 연출(경주의 물리 계산 등)이 결과를 정함: 확률이 가중치와 정확히 맞는다고 보장하기 어려워 기각.

## Consequences

- 추첨 한 번은 가게 하나로 끝나며 다시 돌릴 수 없다.
- 연출은 결과를 입력으로 받아야 한다. 경주는 정해진 가게가 1등이 되도록, 플링코는 공이 정해진 칸에 떨어지도록 그린다.
- 나중에 들어온 팀원은 저장된 결과로 같은 연출을 다시 볼 수 있다.
