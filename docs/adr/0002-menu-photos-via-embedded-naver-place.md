# 메뉴판과 사진은 네이버 플레이스 페이지를 띄워서 보여 준다

네이버는 가게의 메뉴나 사진을 주는 공개 API가 없고, naver.com의 robots.txt는 수집을 막고 있다. 그래서 메뉴와 사진을 우리 DB에 긁어 오지 않고, 가게의 네이버 플레이스 페이지(m.place.naver.com)를 앱 안의 iframe으로 띄운다. 정보가 항상 최신이고 저작권 있는 내용을 복제하지 않는 대신, 네이버 광고가 함께 보이고 네이버가 임베드를 막으면 새 창 열기로 대신한다.

## Considered Options

- 사람들이 사진과 메뉴를 직접 올리기: 처음엔 비어 있고 저장 공간과 부적절한 사진 관리 부담이 커서 기각.
- 네이버 페이지 수집: 약관과 robots.txt 위반 위험으로 기각.

## Consequences

- 가게마다 네이버 플레이스 ID가 필요한데 검색 API는 이를 주지 않는다. 추가할 때 공유 링크를 선택으로 받는다. ID가 없으면 앱 안에 띄울 수 없으므로(네이버 검색·지도 화면은 iframe을 막는다) 네이버 지도 검색을 새 창으로 연다.
